# POMOLOG

集中を、積み重ねよう。React + TypeScript + Viteによる学習記録PWAです。

## 起動

検証環境: Node.js 24.18.0 / npm 11.16.0 / Windows。

```powershell
npm ci
npm run dev
```

`http://127.0.0.1:5173` を開きます。本番用のPWA・オフライン動作は次で確認できます。

```powershell
npm run build
npm run preview
```

公開・Firebase設定・有料サービスは不要です。スマホ実機からローカル開発サーバーを見る場合は `npm run dev -- --host 0.0.0.0` を使用します。ただしLANのHTTP接続ではWeb Locks・Service Worker・ブラウザ通知などの機能が制限され、安全な編集ロックが使えない場合は編集を停止します。編集と本番のPWA機能はHTTPSまたはlocalhostで確認します。

## Phase 1 / 1.1 / 2 / 3 の実装

- タイトル→タイマーと学習項目・問題数→本日の集計→メモ・履歴の順に配置。PCはタイマーと学習入力を左右、スマホは縦に配置。1366×768・1280×720で主要操作を画面内に表示。
- 既存ロゴ原本は保ち、CSSの表示枠で時計マークを切り出して拡大。
- 初期教科7種類をユーザー管理のマスターとして登録。教科→中項目→小項目を順に選択でき、中項目・小項目は未選択でも記録可能。
- 「学習項目管理」で全階層の追加・改名・上下移動・アーカイブ・復元。親をアーカイブすると子も候補から隠れます。学習中も管理画面に切り替えられます。
- 高校基礎テンプレートを必要な教科だけ選んで一括追加。初期状態では子項目を強制登録せず、追加後は自由に編集でき、再追加でも重複しません。
- 項目IDと親IDで関係を管理し、記録には当時の表示名も保持。改名・アーカイブで過去の記録は変わりません。
- 集中20分で達成。25分で一度だけ通知し、計測を継続して超過時間を表示。
- 明示的な一時停止・休憩・再開・セット終了。自動終了・自動移行は行いません。
- 終了後に学習項目、開始・終了、集中時間、正解・不正解、メモを修正して保存。
- 正解／不正解カウントと直前の取り消し、正答率計算。
- 本日の保存済み集計、最近の履歴、全履歴、JSONエクスポート。
- 履歴の詳細確認、期間・3階層・キーワード・達成判定の複合検索、保存済み記録の編集。項目を変更しない編集では当時の名称を保持します。
- 確認ダイアログ付きの論理削除と「削除済み」一覧からの復元。削除記録もJSON出力に含まれます。
- 今日・今週・今月・全期間の統計と項目ID別集計。改名・アーカイブ済みの項目も現在の名前で集計し、履歴詳細では当時の名前を表示します。
- 日別集中時間、学習時間の累積、教科別比較、日別正答率のグラフ。全期間の日別グラフは直近30日、合計と項目別比較は全履歴が対象です。
- localStorageで進行中・一時停止・休憩・終了確認を復元。確認フォームでの未保存の修正内容はリロードすると終了時の値に戻ります。
- 保存できない場合は操作を確定せずエラー表示。壊れた保存データ・未知のスキーマを黙って上書きしません。
- Web Locksで同一ブラウザ・同一originの編集タブを1つに制限します。待機タブは所有タブの終了後に自動取得し、最新データを読み直してから編集できます。開発時のStrictModeにも対応。ページ離脱時は取得待ち要求の取消し／所有ロックの解放を行い、復帰時は再取得します。
- ロックをlocalStorageに保存せず、ブラウザが管理する実際の取得結果と要求ごとの所有者IDで判定します。古い要求は取り消し、所有者の異常終了・クラッシュ後はブラウザによる解放を待って安全に再取得します。経過時間だけを理由に生存中の所有者からロックを奪う処理はありません。
- Web Locks未対応・取得エラー時はデータ保護のため編集を停止し、競合とは別のエラーを表示します。対応ブラウザでHTTPSまたはlocalhostから使用してください。
- manifest、元ロゴから生成したアイコン、本番ビルドのオフラインシェル。

## 計測・通知・保存について

描画更新回数ではなく、保存した時刻から集中時間を計算します。集中中にページを閉じた時間も集中として扱います。一時停止・休憩で閉じた時間は含めません。終了後の確認中も増えません。20分未満の記録も保存でき、20分以上は何分続けても達成セット1回です。

25分の通知は画面内で表示し、許可があればブラウザ通知も試みます。ブラウザを閉じている間の配信は保証せず、再表示時に未通知の到達を検出します。通知済みフラグは配信前に保存するため重複を防げますが、その保存直後にブラウザが終了した場合などは通知が欠落する可能性があります。OS・ブラウザによるバックグラウンド抑制も初版の保証対象外です。

記録はこのブラウザのこのoriginに保存されます。開発サーバーとpreviewはポートが異なるので別の保存領域です。ブラウザのデータ削除で記録も消えるため、JSONを書き出して保管してください。初版ではインポート・端末間同期を実装していません。

Phase 3の保存形式はv3です。旧v1・v2データは編集ロック取得後に自動移行します。移行前のJSON原文は `pomolog.backup.v1.<UUID>` または `pomolog.backup.v2.<UUID>` に退避し、退避に失敗した場合は旧データを上書きせず編集を停止します。v1はメモリ上でv2を経由してv3へ変換し、保存は最後の一度だけ行います。既存バックアップは保持します。旧形式の自由入力は同じ親の同名項目をまとめ、安定IDを割り当てます。小項目だけがある旧記録には管理用の「未分類（旧データ）」中項目を補いますが、記録の表示名はそのままです。詳細は [Phase 2設計](docs/PHASE2_PLAN.md) と [Phase 3完了報告](docs/PHASE3_REPORT.md) を参照してください。

統計は端末のローカル時間と開始日を基準にします。週は月曜日始まりで、日付をまたぐ学習も集中時間全体を開始日に含めます。保存済みの未削除記録だけが対象で、進行中セットは含みません。正答率は合計正解数÷合計問題数です。問題数0の記録も集中時間・達成セットに含め、合計問題数0の正答率は「—」で表示します。

## 検証

```powershell
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run format:check
npm audit
```

Playwrightは本番ビルド（4173）と開発サーバー（5181）を起動します。本番はPCとPixel 7相当のChromium、開発モードはインストール済みの通常版Chrome（`channel: chrome`）で検証します。通常版Chromeがない環境では `npx playwright install chrome` で準備できます。両ポートはテスト用に空けてください。

時間はテスト内で制御し、20分・25分の境界を待たずに検証します。オフライン復元、通知重複防止、カウント・取り消し、確認修正・保存、所有権・タブ終了・クラッシュ・ページ離脱復帰・データ保持、画面の並びと主要操作の表示範囲も対象です。履歴の検索・編集・削除・復元・保存失敗、旧形式の原文保全、ローカル日付境界・月末・年末・夏時間、加重正答率、3階層集計も検証します。ブラウザ全体のクラッシュ試験は `test-results/` 内の専用プロファイルで実行し、実際のユーザープロファイルは使用しません。iOS Safari・実機のOS通知・ホーム画面への追加は別途確認が必要です。
