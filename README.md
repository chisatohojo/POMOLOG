# POMOLOG

集中を、積み重ねよう。React + TypeScript + Viteによる学習記録PWAです。

## 起動

検証環境: Node.js 24.18.0 / npm 11.16.0 / Windows。

```powershell
npm ci
npm run dev
```

`http://127.0.0.1:5173` を開きます。本番用のPWA・オフライン動作は次で確認できます。

```powershell
npm run build
npm run preview
```

公開・Firebase設定・有料サービスは不要です。スマホ実機からローカル開発サーバーを見る場合は `npm run dev -- --host 0.0.0.0` を使用します。ただしLANのHTTP接続ではService Worker・ブラウザ通知などの機能が制限されます。本番のPWA機能はHTTPSまたはlocalhostで確認します。

## Phase 1 の実装

- PCは左右、スマホは縦に配置したタイマー・学習項目・問題数・メモ。
- 初期教科7種類、中項目・小項目の自由入力。マスター管理は後続Phase。
- 集中20分で達成。25分で一度だけ通知し、計測を継続して超過時間を表示。
- 明示的な一時停止・休憩・再開・セット終了。自動終了・自動移行は行いません。
- 終了後に学習項目、開始・終了、集中時間、正解・不正解、メモを修正して保存。
- 正解／不正解カウントと直前の取り消し、正答率計算。
- 本日の保存済み集計、最近の履歴、全履歴、JSONエクスポート。
- localStorageで進行中・一時停止・休憩・終了確認を復元。確認フォームでの未保存の修正内容はリロードすると終了時の値に戻ります。
- 保存できない場合は操作を確定せずエラー表示。壊れた保存データ・未知のスキーマを黙って上書きしません。
- Web Locks対応環境では同一ブラウザ・同一originの編集タブを1つに制限します。もう一つのタブは読み取り専用となり、編集タブを閉じた後の再読み込みで操作できます。Web Locks未対応環境は単一タブで使用してください。
- manifest、元ロゴから生成したアイコン、本番ビルドのオフラインシェル。

## 計測・通知・保存について

描画更新回数ではなく、保存した時刻から集中時間を計算します。集中中にページを閉じた時間も集中として扱います。一時停止・休憩で閉じた時間は含めません。終了後の確認中も増えません。20分未満の記録も保存でき、20分以上は何分続けても達成セット1回です。

25分の通知は画面内で表示し、許可があればブラウザ通知も試みます。ブラウザを閉じている間の配信は保証せず、再表示時に未通知の到達を検出します。通知済みフラグは配信前に保存するため重複を防げますが、その保存直後にブラウザが終了した場合などは通知が欠落する可能性があります。OS・ブラウザによるバックグラウンド抑制も初版の保証対象外です。

記録はこのブラウザのこのoriginに保存されます。開発サーバーとpreviewはポートが異なるので別の保存領域です。ブラウザのデータ削除で記録も消えるため、JSONを書き出して保管してください。初版ではインポート・端末間同期を実装していません。

## 検証

```powershell
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run format:check
npm audit
```

Playwrightは本番ビルドを起動し、PC版ChromeとPixel 7相当のChromeで実行します。時間はテスト内で制御し、20分・25分の境界を待たずに検証します。オフライン復元、通知重複防止、カウント・取り消し、確認修正・保存、タブ競合、横スクロールの有無も対象です。iOS Safari・実機のOS通知・ホーム画面への追加は別途確認が必要です。

## ファイル構成と後続Phase

| ファイル                                                 | 役割                                                |
| -------------------------------------------------------- | --------------------------------------------------- |
| `src/domain/model.ts`                                    | 保存スキーマ、純粋なタイマー状態遷移・計算          |
| `src/data/repository.ts`                                 | Repository、localStorage保存、version検証・移行入口 |
| `src/app/store.ts`                                       | 状態遷移・永続化・通知の仲介                        |
| `src/App.tsx`, `src/components/`, `src/styles.css`       | レスポンシブUI・確認入力                            |
| `vite.config.ts`, `public/`, `scripts/prepare-icons.mjs` | PWA・アイコン生成                                   |
| `src/**/*.test.ts`, `e2e/`                               | 単体テスト・ブラウザテスト                          |
| `docs/ARCHITECTURE.md`                                   | 設計・Phase計画・保存と通知の契約                   |
| `docs/PHASE1_REPORT.md`                                  | 実装・検証結果・残課題                              |

アイコンを再生成する場合は `npm run icons`。原本 `POMOLOG_icon.png` は変更しません。

教科階層の追加・編集、履歴編集、日／週／月／累計・学習項目別統計、Firebase Sparkでの認証・同期・公開は後続Phaseです。クラウド用SDK・認証情報は含めていません。設計の詳細は [アーキテクチャと実装計画](docs/ARCHITECTURE.md) を参照してください。
