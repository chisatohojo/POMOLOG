## 方針

- React + TypeScript + Vite。外部フォント・有料API・サーバー依存なし。
- `domain/` は純粋な状態遷移・時間計算・記録モデル。React、ブラウザ、Firebaseに依存させない。
- `data/` は Repository インターフェースと localStorage 実装。単一の version付きJSONに進行中セットと履歴をまとめ、終了・保存を一度の書き込みで確定する。
- `app/` は状態遷移と保存・通知を仲介する。保存できない操作は確定させず、エラーを表示する。
- `components/` は表示と入力。250msの描画更新は経過時間の加算には使用しない。
- 現行v3保存形式は `items` マスターと、項目ID＋表示名スナップショット付きの学習記録を同一ドキュメントに保存する。Phase 2のv2から、記録ごとの `deletedAt` を追加する。`domain/learning.ts` に階層制約・操作、`domain/templates.ts` に独立したテンプレート定義と重複しない適用処理を置く。
- `data/legacyV1.ts`・`data/legacyV2.ts` で旧形式を検証し、`data/migrations.ts` の純粋・決定的な変換でv1→v2→v3へ移行する。読み込みは保存せず、ロック取得後の `prepareForEditing` で入力バージョンのJSON原文を退避してからv3を一度だけ保存する。移行に失敗した場合は編集権限を開放し、元データを保つ。
- スキーマ検証、固定ID、ミリ秒のepoch時刻、`updatedAt`、三階層の学習項目スナップショットを保存する。将来はRepositoryにFirebase実装と明示的なスキーマ移行を追加する。派生値（達成、正答率）は保存せず再計算する。

## タイマーの契約

待機 → 集中 → 一時停止／休憩 → 集中、または手動終了 → 確認 → 保存 → 待機。

- 集中時間 = 確定済みの集中時間 + 現在時刻 − 最後の集中開始時刻。一時停止・休憩は加算しない。
- 20分以上で1セット達成。25分以上でも1セット。20分では通知しない。
- 25分の通知フラグを保存してから通知する。画面内の通知を基本とし、許可がある場合にブラウザ通知も送る。
- 25分を超えても停止・自動遷移しない。手動終了時に開始・終了・集中時間を固定し、確認中・リロード中に加算しない。
- 集中中にブラウザを閉じた時間は集中として復元する。一時停止・休憩で閉じた時間は加算しない。閉じている間の通知配信は保証しない。再表示時に未通知の25分到達を検出する。
- 時計を過去に変更した場合の負の差分は0に丸める。手動のシステム時計変更を正確に補正する機能は初版対象外。
- 保存失敗・未知バージョン・壊れたデータは明示して、既存データを黙って初期化しない。ブラウザのデータ消去に備えJSONエクスポートを提供する。
- Web Locksで編集可能なタブを1つに制限する。未対応・取得失敗時は編集を停止する。所有権は実際の取得コールバックと要求ごとのIDで判定し、AppStoreの書込み直前にも確認する。revision検証も維持する。
- 取得要求はAbortSignal付きキューで待機する。StrictModeのcleanup・ページ離脱では待機要求を取消し、取得済みなら即時に書込権限を失効させてロックを解放する。復帰時は再取得する。引継ぎ時はロックを保持して最新ドキュメントを読み直した後にUIを有効化する。
- localStorageに期限付きロックは置かない。旧要求はキャンセルと要求ID照合で無効化し、終了・クラッシュしたクライアントのロックはブラウザが解放する。時刻・タブの非表示・応答遅延だけで生存中の所有者を失効させたり、`steal`を使って奪取したりしない。

## 履歴・統計の契約

- 編集・削除・復元はタイマーと同じAppStore・Repository・Web Locks・revision検証を経由する。編集フォームが取得した `expectedUpdatedAt` も照合し、別タブ更新後の古い内容で上書きしない。
- `id` と `createdAt` は維持し、`updatedAt` は単調増加させる。削除は `deletedAt` の設定、復元はnullへの更新とし、将来の同期で削除・復元を伝播できる。物理削除は行わない。
- 履歴の同じ項目IDへの編集では名称スナップショットを保持し、項目を変えた場合だけマスターから取得する。統計はIDで集計して現在名を使う。アーカイブ済みも含める。
- `domain/statistics.ts` が保存済みの未削除記録から検索・集計・日別系列を導出する。正答率は合計正解数÷合計問題数、問題数0は率なし。進行中セットは含めない。
- 端末ローカルの実際のカレンダー境界を使い、固定24時間による日付計算はしない。日付をまたぐ記録は集中時間全体を開始日に帰属させる。集計結果は保存しない。
- 現行の確定集中時間 `focusMs` と集計処理を分離する。将来は保存形式に集中区間の開始・終了時刻を追加して日付をまたぐ区間の分配を拡張できる。既存記録から区間を推測して生成しない。
- SVG・CSSのグラフと数値表を併設する。全期間の合計・項目別比較は全履歴、日別グラフは直近30日とし、画面に対象範囲を明記する。
