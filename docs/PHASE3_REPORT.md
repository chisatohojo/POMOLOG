## 実装内容

### 履歴

- 開始日時が新しい順の一覧と個別詳細。開始・終了、当時の教科／中項目／小項目、実集中時間、達成判定、正解・不正解・合計、正答率、メモ、作成・更新・削除日時を確認できる。
- 開始日の範囲、3階層の項目ID、キーワード、達成／未達成をANDで検索。キーワードは当時の名称・現在のマスター名称・メモを対象とし、空白区切りの語もANDで照合する。日付範囲の逆転はエラー表示する。
- 保存済み記録の日時・集中時間・項目・正解／不正解・メモを編集。終了≧開始、集中時間≦経過時間、整数・上限・必須項目など既存の検証を共通フォームとスキーマで適用する。
- 項目IDを変更しない場合は当時の名称スナップショットを保持。項目を変更した場合は選択したマスターの名称を取得する。改名・アーカイブ済みの記録も、そのままの分類で編集できる。
- 削除前にモーダルで確認し、`deletedAt` を設定する論理削除を実装。「削除済み」一覧から復元できる。削除中も記録本体を残し、通常の履歴・本日の集計・統計から除外する。

### 統計・グラフ

- 「統計」画面を追加。今日／今週（月曜日始まり）／今月／全期間を切り替え、集中時間・達成セット・セッション数・問題数・正解数・不正解数・正答率を表示する。
- 正答率は合計正解数÷合計問題数。問題数0のセッションも集中時間・セット数・セッション数に含め、合計問題数0は「—」で表示する。
- 教科→中項目→小項目の絞り込みと項目別集計。表示名ではなくIDでまとめ、改名・アーカイブ済み項目も同じIDで集計する。現在名とアーカイブ状態を表示し、下位項目の未選択も独立した行に含める。
- 保存済みセッションから毎回導出し、進行中タイマーは含めない。重複ID入力は更新日時と削除状態で一意化して二重計上を防ぐ。通常保存ではスキーマでもID重複を拒否する。
- 日別集中時間の棒グラフ、表示期間内の累積集中時間、教科別比較、日別の加重正答率をSVG／CSSで実装。解答のない日は正答率の線をつながず、数値表も併設した。
- PC・スマホの配置を調整。グラフは画面幅に収まり、項目別の表はスマホで横スクロールできる。

### 日付のルール

- 端末ローカルのカレンダー境界を使用する。日付計算に固定24時間を使わず、夏時間による23時間／25時間の日にも対応する。
- セッション全体を開始日に帰属させる。日付をまたぐ場合も集中時間を分割しない。ルールと対象期間を画面に明記した。
- 全期間の合計・項目別比較は全履歴。全期間の日別グラフは今日を含む直近30日に限定し、表示範囲を画面に明記する。
- 集計処理を `domain/statistics.ts` に分離。将来は集中区間の時刻情報を保存形式へ追加し、日付をまたぐ分配を拡張できる。既存の合計時間から区間を推測して保存しない。

## データ保全・互換性

- 現行保存形式をv3とし、セッションへ `deletedAt: number | null` を追加した。既存のID・時刻・スナップショット・項目マスター・タイマー状態を維持する。
- v1・v2を各旧スキーマで検証し、v1→v2→v3をメモリ上で変換する。編集ロック取得後にのみ、最終v3を一度保存する。単なる読み込み・待機タブでは移行を書き込まない。
- 入力のJSON原文を `pomolog.backup.v1.<UUID>`／`pomolog.backup.v2.<UUID>` に保存・照合してから本体を書き込む。既存退避を削除・上書きせず、失敗時は元データを保持する。再試行で項目IDや記録を重複生成しない。
- 未知バージョン・不正な参照・壊れたデータを黙って初期化しない。
- 編集・削除・復元は既存AppStoreとRepositoryを経由する。Web Locksの所有権、保存直前のrevision、対象記録の `expectedUpdatedAt` を照合する。タブ引継ぎ後の古い編集フォームによる上書きも拒否する。
- セッションID・作成日時は固定し、更新日時を単調増加させる。削除の墓標と復元後の更新日時により、将来の同期で削除・復元を伝播できる構造にした。同期自体は未実装。
- 保存失敗時は確定させず、編集入力や削除対象を保持してエラー表示する。
- JSONエクスポートは全セッション（削除済みを含む）・全マスター・進行中タイマーをv3のまま保持する。実ユーザーの保存データに対する変更・削除は行っていない。
