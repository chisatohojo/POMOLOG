# Phase 1 完了報告

実施日: 2026-10-11（Asia/Tokyo）

## 実装内容

既存ファイルは `POMOLOG_icon.png` のみでした。原本を保ち、React + TypeScript + Viteの新規基盤とローカルGitリポジトリを作成しました。

- コーラル・チャコール・白のレスポンシブUI。PCはタイマーと入力を左右、スマホは縦に配置。
- 集中20分ちょうどから達成、25分ちょうどから一度だけ通知。20分では通知しない。25分以降は超過時間を表示して計測継続。
- 一時停止・休憩・再開、明示的なセット終了。確認中も含め、自動で次の集中／休憩へ移行しない。
- 時刻ベースの計算とversion付きlocalStorage保存。集中・一時停止・休憩・終了確認をリロード復元。
- 初期教科7種類と中項目・小項目の入力、正解／不正解カウント、取り消し、正答率、メモ。
- 終了後に学習項目・開始終了時刻・集中時間・カウント・メモを確認・修正して保存。
- 20分未満も履歴保存可能。20分以上は継続時間にかかわらず達成1セット。
- 本日の保存済み集中時間・達成セット・問題数・正解数・正答率、最近の履歴・全履歴、PC／スマホからのJSONエクスポート。
- 保存失敗時のエラーと再試行、破損／未知スキーマの上書き防止、Web Locksによる複数タブ編集防止、revisionによる競合検出。
- manifest・ロゴ・192／512pxアイコン・Service Workerによる本番用オフラインシェル。外部通知サービスは使用しない。

## 残課題・初版の制約

- 教科→中項目→小項目のマスター追加・編集と安定した親子IDの導入。現在は初期教科と入力ラベルをセッションのスナップショットとして保存する。
- 保存後の履歴編集、期間別・累計・項目別統計。現在の本日集計はセット開始日の端末ローカル日付に帰属する。
- JSONのインポート、データ移行画面。エクスポートはスキーマversion・進行中セット・履歴を含む。
- Firebase Sparkの認証・同期・Hosting、無料枠と競合解決の設計・検証。
- iOS Safari・実機でのホーム画面追加とOS通知の検証。今回のスマホ検証はChromeのエミュレーション。
- ブラウザが閉じている間の通知配信、バックグラウンドでの定時通知は保証しない。次に表示された際に未通知の25分到達を検出する。
- 確認フォームの未保存の修正はリロードすると終了時の値に戻る。保存失敗時は画面上の入力を保持する。
- localStorageの容量、ブラウザによるデータ削除、端末時計の手動変更に制約がある。長期利用に向けてIndexedDB等のRepository実装を検討する。
- Web Locks非対応ブラウザは単一タブで利用する。revision検証は行うが、同時書き込みの完全な排他はWeb Locksに依存する。

Firebaseリソース作成、外部公開、クラウド同期、有料サービスの契約・操作は実施していません。
